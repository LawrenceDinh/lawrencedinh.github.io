Hermes Pi / Personal project

Personal automation.

Hermes Pi is a personal automation assistant that can connect to an authorized Google account for Gmail monitoring and configured notifications.

Operated by Lawrence Dinh
01

What it does

Authorized monitoring

After explicit Google OAuth authorization, Hermes Pi can monitor Gmail for new messages.

Configured outputs

It can create notifications and automation outputs configured for the operator’s workflow.

Personal workflow

Hermes Pi is designed for the operator’s personal use, not as a public signup service or commercial SaaS.

No advertising use

Google user data is not sold and is not used for advertising.

02

Google Account Access

  • Access requires the Google account owner to explicitly approve the requested Google OAuth permissions.
  • Hermes Pi uses Google user data only to provide the authorized Gmail-monitoring functionality.
  • Authorized data may be used for message monitoring, configured notifications, duplicate prevention, and troubleshooting.
  • Google access can be revoked through the user’s Google Account permissions.
  • Gmail data is not sold or used for advertising.
